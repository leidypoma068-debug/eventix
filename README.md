# EVENTIX — Sistema de Venta de Entradas para Eventos

Sistema para consultar eventos, comprar entradas digitales y
gestionar el ingreso mediante códigos QR.

Permite al administrador gestionar eventos, controlar el aforo
y consultar ventas, reportes y estadísticas.

## Tecnologías

- Laravel 10.
- React 18.
- Inertia.
- Tailwind CSS.

## Diseño del sistema

Arquitectura prevista: Onion.

El desarrollo seguirá el documento de requisitos SRS y
el diseño de interfaces de EVENTIX.
